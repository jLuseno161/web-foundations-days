About QuickNotes

QuickNotes is a simple note-taking app designed to help you capture ideas quickly and easily. Whether you're jotting down a quick reminder or brainstorming, it keeps all your notes in one place so you stay organized.

How to use QuickNotes

  1. Type your note in the input field.
  2. Click the "Add Note" button to save it.
  3. Your notes will be displayed below the input field.

Features

  • Add new notes
  • View your existing notes
  • Delete notes you no longer need
  • Clear all notes at once

Keyboard Shortcuts

Shortcut Action
Ctrl + Enter Add a new note
Ctrl + Shift + Delete Clear all notes
Ctrl + S Save notes
